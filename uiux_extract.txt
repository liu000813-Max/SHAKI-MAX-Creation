[P0][Normal] SHAKI AI Product Match UI/UX Design Spec
[P1][Normal] SHAKI AI Product Match — UI/UX Design Specification
[P2][Normal] Desktop 1440px | Figma-ready + Codex-ready | 中英文双语
[P3][Heading 1] 1. 设计目标 / Design Goal
[P4][Normal] 核心体验不是“聊天”，而是“输入客户 → AI完成研究 → 快速挑选产品 → 一键形成客户提案”。 / The core experience is not chat-first; it is client-first, recommendation-first and proposal-first.
[P5][Heading 1] 2. 视觉方向 / Visual Direction
[P6][Normal] 字体建议 / Font: Inter + Microsoft YaHei / Noto Sans SC. Desktop 1440px first, minimum supported 1280px.
[P7][Heading 1] 3. 布局系统 / Layout System
[P8][Heading 1] 4. 全局组件 / Global Components
[P9][Heading 1] 5. 页面地图 / Page Map
[P10][Heading 1] 6. P01 登录 / P01 Login
[P11][Normal] 目的 / Purpose: 快速进入系统。 / Fast entry.
[P12][Normal] 1440px布局 / Layout: Centered auth card, logo top, language switch top-right.
[P13][Heading 1] 7. P02 工作台 / P02 Dashboard
[P14][Normal] 目的 / Purpose: 让业务员看到今日机会和最近客户。 / Surface today’s opportunities and recent clients.
[P15][Normal] 1440px布局 / Layout: 240px sidebar + 64px topbar + 1200px content; KPI row + recent clients + opportunity cards.
[P16][Heading 1] 8. P03 新客户 / P03 New Client
[P17][Normal] 目的 / Purpose: 核心入口：客户主营品类 + 官网 + 社媒。 / Core input.
[P18][Normal] 1440px布局 / Layout: Two-column: left 720px input form, right 360px “What AI will analyze”.
[P19][Heading 1] 9. P04 客户研究中 / P04 Researching
[P20][Normal] 目的 / Purpose: 给用户可解释的进度感。 / Provide transparent progress.
[P21][Normal] 1440px布局 / Layout: Centered progress panel + research steps + estimated phase labels; no fake percentages.
[P22][Heading 1] 10. P05 客户情报 / P05 Client Intelligence
[P23][Normal] 目的 / Purpose: 让业务员确认“AI理解的客户”。 / Let sales verify the client interpretation before recommendations.
[P24][Normal] 1440px布局 / Layout: Top client summary; 3-column intelligence cards; product portfolio map; opportunities panel.
[P25][Heading 1] 11. P06 推荐结果 / P06 Recommendations
[P26][Normal] 目的 / Purpose: 核心工作页：让业务员快速从20个高匹配中选5个。 / Core decision page.
[P27][Normal] 1440px布局 / Layout: Top summary strip + filter bar + 2/3 product grid + right-side shortlist panel.
[P28][Heading 1] 12. P07 产品智能 / P07 Product Intelligence
[P29][Normal] 目的 / Purpose: 展示SKU事实、产品分数和针对当前客户的解释。 / Show verified SKU facts, scores and client-specific reasoning.
[P30][Normal] 1440px布局 / Layout: Left 56% media gallery + right 44% product intelligence; lower section for score breakdown and evidence.
[P31][Heading 1] 13. P08 产品对比 / P08 Compare
[P32][Normal] 目的 / Purpose: 帮助业务员在2–5款产品中做最后选择。 / Final decision support across 2–5 products.
[P33][Normal] 1440px布局 / Layout: Sticky comparison header + rows grouped by Fit, Commercial, Product, Customization.
[P34][Heading 1] 14. P09 方案编辑 / P09 Proposal Builder
[P35][Normal] 目的 / Purpose: 把推荐变成客户可直接接收的方案。 / Turn recommendations into a client-ready proposal.
[P36][Normal] 1440px布局 / Layout: Left 70% editable canvas + right 30% controls; drag reorder.
[P37][Heading 1] 15. P10 方案预览 / P10 Proposal Preview
[P38][Normal] 目的 / Purpose: 发送前检查双语和视觉。 / Final visual and language QA.
[P39][Normal] 1440px布局 / Layout: Full-width centered A4-like page preview with right-side action rail.
[P40][Heading 1] 16. P11 客户分享页 / P11 Client Share
[P41][Normal] 目的 / Purpose: 客户看到的是精选提案，不看到内部评分。 / External page hides internal scoring.
[P42][Normal] 1440px布局 / Layout: Minimal public page; client logo/name; curated products; contact CTA; mobile-responsive.
[P43][Heading 1] 17. P12 产品库 / P12 Product Library
[P44][Normal] 目的 / Purpose: 让产品经理维护Product Intelligence。 / Maintain Product Intelligence.
[P45][Normal] 1440px布局 / Layout: Filter bar + data table + right drawer for editing.
[P46][Heading 1] 18. P13 数据分析 / P13 Analytics
[P47][Normal] 目的 / Purpose: 看推荐与销售反馈。 / Connect recommendations with sales outcomes.
[P48][Normal] 1440px布局 / Layout: KPI row + funnel + market chart + product leaderboard + recommendation quality panel.
[P49][Heading 1] 19. P14 设置 / P14 Settings
[P50][Normal] 目的 / Purpose: 账户、语言、评分配置和系统偏好。 / Account, language and configurable scoring.
[P51][Normal] 1440px布局 / Layout: Tabbed settings.
[P52][Heading 1] 20. 推荐卡设计规范 / Recommendation Card Spec
[P53][Heading 1] 21. 六维评分可视化 / Six-Dimension Score Visualization
[P54][Normal] 推荐使用横向六条分数条，不建议第一版使用复杂雷达图，以保证信息密度与可读性。 / Use six horizontal score bars rather than radar charts in V1 for clarity and density.
[P55][Heading 1] 22. 状态系统 / State System
[P56][Heading 1] 23. 双语文案原则 / Bilingual Copy Rules
[P57][List Bullet] 内部操作文案优先中文，英文作为第二语言。 — Internal workflow can prioritize Chinese, with English as the paired language.
[P58][List Bullet] 客户页面默认英文，允许切换中文。 — Client-facing pages default to English, with Chinese as an option.
[P59][List Bullet] 同一个术语在全系统保持一致，例如“适配分 / Fit Score”。 — The same concept must use one canonical term everywhere, e.g. “Fit Score”.
[P60][Heading 1] 24. Figma命名规范 / Figma Naming
[P61][Heading 1] 25. Codex实现优先级 / Codex Implementation Order
[P62][List Bullet] 01 — App shell: sidebar, topbar, i18n, design tokens.
[P63][List Bullet] 02 — P03 New Client + API contract.
[P64][List Bullet] 03 — P04 Researching states.
[P65][List Bullet] 04 — P05 Client Intelligence.
[P66][List Bullet] 05 — P06 Recommendations and score components.
[P67][List Bullet] 06 — P07 Product Intelligence + evidence drawer.
[P68][List Bullet] 07 — P08 Compare.
[P69][List Bullet] 08 — P09/P10 Proposal builder + preview.
[P70][List Bullet] 09 — P11 client-facing share page.
[P71][List Bullet] 10 — Product Library + bulk import.
[P72][List Bullet] 11 — Analytics and feedback loop.
[P73][List Bullet] 12 — QA: bilingual, responsive 1280/1440, loading/error/empty states.
[P74][Heading 1] 26. UI验收标准 / UI Acceptance Criteria
[P75][List Bullet] At 1440px, no horizontal scroll on core pages.
[P76][List Bullet] All core actions visible without forcing the user to open a menu.
[P77][List Bullet] Every AI-generated recommendation has a visible reason and confidence label.
[P78][List Bullet] No client-facing page exposes internal scores or internal notes.
[P79][List Bullet] All pages have loading, empty, error and success states where applicable.
[P80][List Bullet] Chinese and English do not cause clipping or layout shifts.
[P81][List Bullet] Product cards remain readable at 1280px.
[P82][List Bullet] Proposal can be previewed before sharing.
[P83][List Bullet] No primary button uses ambiguous copy such as “OK”; actions are explicit.
